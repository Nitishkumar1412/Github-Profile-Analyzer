# GitHub Profile Analyzer

Analyze any public GitHub profile: language breakdown, 12-month contribution heatmap, top repositories and a 0-100 developer score. React + Vite, no backend.

## Run
    npm install
    npm run dev

## Build
    npm run build && npm run preview

## Developer score (100 pts)
Repos 10, Stars 25, Followers 15, Activity 25, Language diversity 15, Account tenure 10.

## Deploy
Push to GitHub and import the repo in Vercel or Netlify (build: `npm run build`, output: `dist`).
